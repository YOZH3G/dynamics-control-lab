# Версия 1.15.0: объекты управления из файла

## Кнопка «Открыть объект…»

Преподаватель описывает объект управления в файле JSON без программного кода: параметры, уравнения состояния, один вход со ступенью и измеряемый выход с запаздыванием. Кнопка «Открыть объект…» на верхней панели открывает описание, добавляет объект в список моделей и строит его страницу: свободный отклик, оценку K, T и L, интервалы, настройку PI и опыт с PI. Результат доступен на странице «Результат модели» с экспортом JSON, CSV, HTML и PDF. Формат описан в разделе 26 руководства.

Описания открытых объектов сохраняются внутри учебного сеанса и автосохранения, поэтому сеанс открывается на другом компьютере без отдельного файла описания. При открытии сеанса программа проверяет описания и повторяет по ним сохранённые расчёты и оценки; при расхождении сеанс не открывается. Описание с тем же ключом, но другим содержанием заменяет прежнее.

## Безопасность формул

Формулы разбираются как дерево выражения и вычисляются обходом дерева, без выполнения кода. Допускаются числа, имена из описания, арифметика, степень с показателем до 100 по модулю и функции `exp`, `log`, `sqrt`, `sin`, `cos`, `tan`, `abs`, `min`, `max`. Атрибуты, вызовы других функций, строки, сравнения и `lambda` отклоняются ещё при открытии файла; тесты проверяют это на попытках вроде `__import__('os')`. Ключ и название объекта не могут совпадать со встроенной моделью или разделом программы; одновременно открыто может быть не больше 10 объектов из файлов.

## Проверка на нагревателе

Пример описания — ёмкость с нагревателем — поставляется с программой (`_internal\data\heater_object.json`). Расчёт по нему совпадает со встроенной моделью «Нагреватель»: температура в свободном отклике и в опыте с PI отличается не больше чем на 10⁻¹² °C, показатели PI и оценки K, T и L одинаковы. Проверка выпуска открывает пример, рассчитывает свободный отклик и опыт с PI и восстанавливает работу после перезапуска (`file_object_verified`).

## Модульность

Версия завершает план модульности объектов: объекты подключаются через реестр моделей, страницы строятся на общей основе, а описанные в файле объекты используют ту же основу. Перенос абсорбера в эту схему отложен, причины — в [дорожной карте](../../ROADMAP.md).

## Другие изменения

- Изменение шума датчика или числа генератора на странице нагревателя больше не делает устаревшим свободный отклик: устаревает только оценка K, T и L, и её можно сразу повторить.
- Список моделей на верхней панели расширяется под длинные названия.
- Время запуска на одной машине по медиане шести запусков: 1,83 с у 1.13.0 и 1,79 с у 1.14.1. Более долгий запуск в CI (2,3–2,5 с) вызван раннерами, а не программой.
