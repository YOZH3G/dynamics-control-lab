# Отчёт о версии 1.6.0

Дата: 8 октября 2026 года.

Выполнены этапы E01–E05 из [ROADMAP_1.6.md](ROADMAP_1.6.md). Программа поддерживает полный экспериментальный цикл: запись, идентификация, независимая проверка, сравнение PI-регуляторов и воспроизводимый протокол.

## Изменения

- Эксперимент, настройки импорта и последний успешный результат идентификации входят в сохранение сеанса и автосохранение. Для восстановления исходный CSV не нужен; сеансы 1.5.4 читаются без преобразования.
- Добавлены название и источник эксперимента, назначение сигналов, рабочий режим, комментарий, прогноз, объяснение остатка и вывод. Учебное задание использует существующий эталонный CSV.
- При переносе T/L в абсорбер опыты сохраняют источник и версию параметров. Сведения видны в сравнении и протоколах; усиление баланса абсорбера сохраняется.
- Независимая запись проверяется при фиксированных K/T/L. Её исходный уровень определяется по участку до ступени. Повторная подгонка не выполняется; большая ошибка сохраняется с предупреждением.
- PI-проверка доступна после подтверждения входа η и выхода концентрации в долях. Сравниваются исходные и предложенные настройки при одинаковых условиях. Учтены знак K, запаздывание, пределы η и защита интегратора.
- Недостижимое задание не считается установившимся. Выход линейной модели не обрезается до физического диапазона; выход за границы требует проверки применимости модели.
- Полный HTML/PDF-протокол различает подгонку, независимую проверку и симуляцию регулирования. Общий CSV и сеанс JSON сохраняют те же результаты. Изменение данных помечает прежние проверки как снимки предыдущего опыта.

## Проверки

- Полный набор из 164 тестов прошёл. После окончательных правок отображения повторно прошли семь проверок экспериментального расчёта и полного цикла интерфейса.
- Проверены положительное и отрицательное K, история до запаздывания, границы η, недостижимое задание, воспроизведение результатов и отказ при неизвестном назначении входа.
- Независимая проверка сохраняет параметры и использует новые время ступени, амплитуду и исходный уровень. Запись без достаточных измерений перехода отклоняется.
- Проверены восстановление после удаления CSV, чтение сеанса 1.5.4, сохранение устаревшего результата и отказ при повреждённых сигналах или показателях проверки.
- Проверка исходного приложения прошла семь встроенных сценариев, идентификацию, экспериментальную проверку PI, экспорт и восстановление после перезапуска окна.
- Готовый Windows EXE 1.6.0 прошёл те же семь встроенных сценариев, идентификацию, экспериментальную проверку PI, экспорт и восстановление сеанса.
- Новые экраны просмотрены при размере окна 1366 × 768. Сравнены исходный экран идентификации и экраны независимой проверки и PI; проверены прокрутка и видимость графиков.
- Руководство и README вычитаны целиком по ru-check. PDF руководства: 22 страницы, 55 ссылок и 264 однострочные ячейки первого столбца. Все страницы отрисованы и просмотрены. Экспериментальный PDF-протокол из четырёх страниц также отрисован и просмотрен.

- Исправлено обрезание подписей осей экспериментального PDF-протокола. Проверка полного цикла контролирует стабильность расположения графиков при экспорте и границы подписей.

## Ограничения

Идентификация и независимая проверка поддерживают одну постоянную ступень и звено первого порядка с запаздыванием. Для проверочной записи используются те же выбранные названия столбцов, разделитель и единицы. Соответствие физических сигналов подтверждает пользователь.

В сеансе хранится последний успешный результат каждой проверки; для нескольких законченных работ сохраняйте отдельные сеансы. PI проверяется в симуляции локальной экспериментальной модели. Проверка не подтверждает работу оборудования или применимость модели вне исследованного режима.

Оценка неопределённости K/T/L и чувствительности регулятора остаётся следующим отдельным этапом. Универсальная система новых моделей в этот выпуск не входит.
