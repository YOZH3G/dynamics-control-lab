# Отчёт о версии 1.5.4

Дата подготовки: 8 октября 2026 года. Выпуск подготовлен из `trunk` для обновления `stable` до того же коммита.

Все задачи согласованной дорожной карты из архива `absorbtion_md_latest_2026-10-06.zip` выполнены. Документ 03 определяет замену старой модели общим материальным балансом. Историческая модель сохранена в теге `archive/pre-balanced-model`; переключатель моделей и миграция прежнего формата не добавлялись.

## Что сделано после 1.5.0

- C06: закреплены зависимости запуска и сборки; проверки на Windows и Linux, сборка и проверка готового Windows EXE выполняются в GitHub Actions.
- C07 и U07: расчёты выполняются в фоне; доступны прогресс, отмена и защита от применения устаревшего результата. Очистку опыта можно отменить, исходные настройки восстанавливаются отдельно.
- U03–U06: регулируемые панели, один или два графика, широкое сравнение, устойчивые цвета опытов, прокрутка и возврат контекста навигации. Окна возвращаются в рабочую область после изменения экрана.
- U08–U09: учебный маршрут, подсказки навигации, группа «Исследование», ввод возмущений долями или процентами. Переключение единиц сохраняет физическое значение; списки разделяются точкой с запятой или новой строкой.
- C09: воспроизводимый шум датчика, фильтр D, инерция механизма и ограничение скорости η. Нулевые настройки сохраняют прежний расчёт. Командная и фактическая η различаются; истинный и измеренный выход показаны отдельно. Добавлен седьмой встроенный сценарий «Шум датчика и ограничения η».
- U10: локализованы инструменты графика, выделяется активный режим. Общий курсор времени показывает значения на двух графиках; ошибку и управление можно показать раздельно. Проверено сохранение видимости обеих панелей после перерисовки.
- C10: импорт экспериментального CSV с выбором столбцов и единиц, оценка K, T и L, наложение модели и просмотр остатка. Есть учебный CSV с известными параметрами. T и L можно перенести в динамику, результат — экспортировать в CSV и JSON.
- Руководство, README и PDF обновлены для текущего интерфейса. Настройки датчика и механизма сохраняются в сценариях, сеансах, протоколах и отчётах.

## Проверки

- 155 тестов проходят, включая настоящие виджеты Tkinter.
- Проверены точное совпадение базовых массивов при отключённых расширениях, повтор шума, действие фильтра, физические границы η, предел скорости и сходимость при уточнении шага.
- Сеанс с шумом, фильтром и механизмом восстанавливает те же массивы измерения, команды, фактической η и выхода.
- Идентификация восстанавливает синтетические эталоны с положительным и отрицательным K, нулевым и дробным L и неравномерным временем. Проверены единицы, экспорт, отмена, переход между разделами и сохранение последнего успешного результата при отказе.
- Некорректное время, пропуски, слабое возбуждение, несколько ступеней, короткая запись, слишком редкие измерения и дрейф исходного режима вызывают объяснимый отказ.
- Windows EXE версии 1.5.4 собран и запущен: проверены Tkinter, семь встроенных сценариев, идентификация учебного CSV, автосохранение и точное восстановление после перезапуска.
- Новые экраны, общий курсор, раздельное управление и остаток модели сняты и просмотрены. Проверено небольшое окно 1366 × 768 с масштабом текста Tk 150%; системный масштаб Windows не переключался.
- Полная вычитка README и руководства по ru-check выполнена. PDF: 20 страниц, 55 внутренних ссылок, 238 однострочных ячеек первого столбца; текст совпадает с Markdown, все страницы просмотрены.

## Что осталось

Незавершённых задач текущей дорожной карты нет. Новые функции требуют отдельного согласования.

Идентификация ограничена одним постоянным ступенчатым воздействием и звеном первого порядка с запаздыванием. Экспериментальный K не заменяет усиление баланса абсорбера. Результат идентификации сохраняется экспортом и не входит в автосохранение лабораторной. Модель сохраняет учебное назначение; она не рассчитывает равновесие и кинетику промышленного аппарата.

В выпуск включены Windows EXE, руководство PDF, этот отчёт, результат проверки EXE и SHA256SUMS.txt.
