# Отчёт о версии 1.8.0

## Выполнено

Реализованы этапы [ROADMAP_1.8.md](ROADMAP_1.8.md). Абсорбер и бак зарегистрированы в общем реестре; описание включает параметры, единицы, сигналы, управляющие каналы, возможности, события и версию расчёта. Адаптеры сохраняют прежние уравнения и результаты. Основной расчёт, восстановление абсорбера, анализ чувствительности, карта настроек и опыты PI бака используют общий запуск.

Страница «Результат модели» показывает группы сигналов с одинаковыми единицами. Общие графики, CSV/HTML/PDF и JSON не содержат ветвлений по именам физических объектов. Учебные графики, формы и предметные протоколы сохранены. Навигация бака показывает только его рабочую страницу и общий результат.

JSON результата версии 1 и общие результаты в сеансе проходят проверку до изменения интерфейса. Успешный импорт отменяет незавершённый расчёт; ошибочный импорт сохраняет задачу и работу. Старые сеансы версий 2/3 открываются. Версии расчёта абсорбера 2 и бака 1 не изменены.

## Изменённые файлы

- `app/model_contract.py`, `app/physical_models.py` — контракт, реестр, адаптеры, проверка и JSON результата.
- `app/model_output.py`, `ui/model_result_page.py` — общий просмотр и экспорт.
- `main.py`, `ui/tank_page.py`, `app/tank.py`, `app/exploration.py`, `app/session_store.py` — подключение к расчётам, навигации и сохранению.
- `tests/test_physical_models.py`, `tests/test_gui_state.py` — эквивалентность, третий тестовый объект, повреждения и гонка импорта.
- `README.md`, `docs.md`, `output/pdf/docs.pdf`, `ROADMAP_1.8.md`, `STATUS_1.8.0.md` — описание версии и проверок.

## Проверки

- Полный набор: 180 тестов. Проверены численная эквивалентность прежним расчётам, физические пределы, повреждённый JSON, старые сеансы и отмена задачи при импорте.
- Третий объект существует только в тестах: запуск, общий интерфейс, JSON, CSV/HTML/PDF и восстановление учебного сеанса.
- Исходная программа и готовый EXE 1.8.0 прошли проверку семи сценариев, идентификации, опытов, бака, общего результата и автосохранения. Отчёт готовой сборки: `release-check.json` в релизе.
- Экраны обоих объектов просмотрены при 1366 × 768; навигация проверена также при 900 × 540. Тесты проверяют видимость обеих панелей и границы легенды.
- Руководство: 26 страниц, 61 внутренняя ссылка, 319 однострочных ячеек первого столбца. Все страницы руководства и шесть страниц общих PDF-отчётов отрисованы и просмотрены.
- Документация прошла полную вычитку ru-text. Структура README сверена со всеми Python-файлами; `git diff --check` выполнен.

Перед публикацией сборка дополнительно проверяется в GitHub Actions на Windows и Linux. В релиз входят EXE, руководство, этот отчёт, результат проверки сборки и SHA256SUMS.txt.

## Ограничения и дальнейшая работа

Встроенных пользовательских моделей по-прежнему две. Тестовый нагреватель проверяет расширяемость и не включён в выбор приложения. Реестр подключает доверенные адаптеры разработчика; пользовательские плагины и редактор уравнений не реализованы. Полные учебные состояния и формы остаются специальными для каждого объекта.

Общий результат бака после сравнения PI показывает номинальный опыт исходных настроек; все восемь опытов находятся в его специализированном протоколе. Самостоятельный JSON хранит результат, но не заменяет полный учебный сеанс. Импортированный снимок не меняет поля расчёта. Прежние физические ограничения бака и локальной идентификации сохраняются.

Следующий научный этап — чувствительность PI к ошибкам идентификации; статистические доверительные интервалы рассматриваются отдельно.
