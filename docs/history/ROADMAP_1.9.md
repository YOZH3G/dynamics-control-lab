# Дорожная карта 1.9: ошибки идентификации и PI бака

Дата: 9 октября 2026 года. Основа — [общий механизм моделей 1.8](ROADMAP_1.8.md).

Выбранная методика: ошибочные оценки K/T/L → настройка PI → проверка на неизменном нелинейном баке. Независимые отклонения описывают ошибки оценки, а не новые физические свойства объекта. Для L используются секунды.

| Этап | Результат | Проверка готовности |
|---|---|---|
| S01 | Сетка ошибок и два контрольных PI | Нулевые ошибки совпадают с номиналом; физические параметры одинаковы |
| S02 | Пять явных требований | Проверены границы порогов, недостижимость и физическая остановка |
| S03 | Срезы ΔL и выбранный отклик | Сравнение исходного, номинального и перенастроенного PI; обе панели видимы |
| S04 | Полный снимок, CSV/HTML/PDF | Старые сеансы открываются; новые восстанавливаются без исходного CSV |
| S05 | Документация и выпуск 1.9.0 | Тесты, интерфейс, PDF, EXE и проверки Windows/Linux |

Статус: S01–S05 реализованы и проверены локально. Публикация версии 1.9.0 выполняется после успешной проверки GitHub Actions. Фактические результаты — в [STATUS_1.9.0.md](STATUS_1.9.0.md).

В 1.9 входит только бак. Сетка показывает прохождение требований в проверенных узлах. Интерполяция, доказательство устойчивости во всём диапазоне, статистические доверительные интервалы и изменение физического объекта с задержкой насоса не входят в этот этап. Перенос методики на абсорбер требует отдельной проверки знака канала и ограничений концентраций.
