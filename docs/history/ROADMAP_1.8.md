# Дорожная карта 1.8: общий механизм физических моделей

Основа — два объекта из [версии 1.7.0](STATUS_1.7.0.md) и [последняя дорожная карта](ROADMAP_1.7.md). Дата: 8 октября 2026 года.

Цель: зарегистрированные модели используют общий выбор, запуск, сигналы, графики, экспорт и снимок результата; самостоятельные уравнения и учебные формы сохраняются.

| Этап | Результат | Проверка готовности |
|---|---|---|
| M01 | Контракт параметров, сигналов, каналов, возможностей, событий и версий | Описания обоих объектов не смешивают единицы и форматы |
| M02 | Реестр и адаптеры существующих расчётов | Числа совпадают с прямым запуском прежних функций |
| M03 | Общая страница результата, группы единиц, CSV/HTML/PDF | Оба объекта используют один просмотр и экспорт |
| M04 | JSON результата и общие снимки в учебном сеансе | Старые сеансы читаются; повреждённые данные не заменяют работу |
| M05 | Проверка расширяемости и выпуск | Тестовый объект проходит запуск, интерфейс, все форматы и восстановление без новых ветвлений в общем слое |

Статус: M01–M05 реализованы и проверены локально. Публикация версии 1.8.0 выполняется после проверки GitHub Actions. Фактические результаты — в [STATUS_1.8.0.md](STATUS_1.8.0.md).

Общее описание содержит доверенные функции адаптера. Импортированный JSON хранит только данные и не регистрирует исполняемый код. Тестовый нагреватель существует только в тестах и не объявляется третьей пользовательской моделью.

Полные учебные состояния, редактор сценариев абсорбера и идентификация остаются специализированными адаптерами. Следующий этап может объединить их только при конкретной потребности. Пользовательские плагины, редактор уравнений и связанные схемы не входят в 1.8. После общего механизма отдельный научный цикл — чувствительность PI к ошибкам идентификации; доверительные интервалы требуют отдельной проверки статистических предположений.
