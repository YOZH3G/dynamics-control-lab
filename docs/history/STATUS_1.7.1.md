# Версия 1.7.1 — Лаборатория динамики и управления

## Изменения

Приложение переименовано в «Лабораторию динамики и управления». Репозиторий: [YOZH3G/dynamics-control-lab](https://github.com/YOZH3G/dynamics-control-lab). Windows-приложение: `DynamicsControlLab.exe`.

Обновлены заголовки интерфейса, основной класс приложения, сценарий сборки, GitHub Actions, имена новых экспортируемых файлов и ссылки на репозиторий. Руководство и его PDF-копия описывают новое название и версию.

## Совместимость

Каталог `%APPDATA%\AbsorptionTrainer` сохранён, чтобы программа загружала прежние сценарии, настройки и автосохранение. Форматы JSON не изменены: сценарии версии 2, запись сеансов версии 3 и чтение версий 2/3. Ранее сохранённые файлы можно открывать под прежними именами. Новые экспорты абсорбера и общие сеансы используют префикс `dynamics_control_`; имена экспортов бака остаются предметными. Исторические релизы сохраняют прежние названия своих вложений.

## Изменённые файлы

- `main.py`, `ui/scenario_editor.py`, `app/scenario_store.py` — название, экспорт и совместимость данных.
- `dynamics_control_lab.spec` вместо `absorption_trainer.spec`, `build_windows.ps1`, `.github/workflows/verify.yml` — сборка и публикация нового EXE.
- `tests/test_gui_state.py`, `tests/test_plotting.py` — обращения к переименованному классу.
- `README.md`, `docs.md`, `output/pdf/docs.pdf`, `STATUS_1.7.1.md` — описание выпуска.
- `ROADMAP.md`, `STATUS_1.7.0.md` — ссылки на переименованный репозиторий.

## Проверка

- Полный набор: 171 тест, все прошли.
- Исходники и `DynamicsControlLab.exe`: успешная проверка запуска, семи сценариев, идентификации, эксперимента, PI бака и восстановления автосохранения.
- Интерфейс: новое название и версия видимы, обе панели графиков бака отображаются.

## Дальнейшая работа

Переименование не меняет физические модели. Дальнейшее развитие следует согласовывать по отдельной дорожной карте; универсальная система физических моделей остаётся следующим архитектурным этапом.
