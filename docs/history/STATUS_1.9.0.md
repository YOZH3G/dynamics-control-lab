# Отчёт о версии 1.9.0

## Выполнено

Добавлен опыт чувствительности PI бака к ошибкам оценки K/T/L. Ошибочная оценка используется для перенастройки регулятора; параметры физического бака, задание, отбор, период и горизонт одинаковы во всех опытах. Исходный PI и PI по номинальной оценке сохранены как два контрольных расчёта. Нелинейные уравнения бака не изменены.

Пользователь задаёт списки ошибок K/T в процентах, отклонения L в секундах и пять порогов: конечной ошибки, IAE, перерегулирования, времени установления и насыщения. Область показывает только проверенные узлы выбранного среза ΔL. Нижний график сравнивает три регулятора; сводка объясняет непрохождение требований.

Сеанс и автосохранение хранят всю сетку, сигналы, источник идентификации, настройки, требования и выбранный опыт. Старые сеансы получают пустой опыт с полями по умолчанию. Повреждённая сетка или показатели отклоняются до замены работы. Изменение новых полей отменяет расчёт без потери актуальности физической идентификации.

Отдельные CSV/HTML/PDF содержат опыт ошибок идентификации. Общий протокол HTML/PDF дополнен сводкой, областью и выбранными откликами; общий CSV включает новые физические сигналы. Полные данные для продолжения работы хранятся в JSON-сеансе.

## Изменённые файлы

- `app/tank_sensitivity.py` — сетка, перенастройка, требования и проверка снимка.
- `app/tank_sensitivity_exporting.py` — графики, CSV и отчёты.
- `ui/tank_sensitivity.py`, `ui/tank_page.py` — форма, выбор опыта и отображение.
- `app/tank.py`, `app/tank_state.py`, `app/tank_exporting.py` — общие показатели PI, совместимость сеанса и полный протокол.
- `tests/test_tank_sensitivity.py`, `tests/test_gui_state.py`, `main.py` — проверки расчёта, импорта, отмены и выпуска.
- `README.md`, `docs.md`, `output/pdf/docs.pdf`, `ROADMAP_1.9.md`, `STATUS_1.9.0.md` — документация.

## Проверки

- Полный набор: 190 тестов. Нулевые ошибки совпадают с номинальным контролем; все настройки проверены прямым запуском прежнего физического расчёта.
- Проверены пять требований, отрицательная ступень задания, недостижимость, остановка, отмена, переполнение чисел и повреждения снимка. Время установления и остальные показатели сверяются с сигналами; неполный горизонт без события отклоняется.
- Новый сеанс точно восстанавливается вместе с выбранным опытом; старый сеанс без блока ошибок открывается. Ошибочный импорт не заменяет работу; изменение требований отменяет фоновый расчёт.
- Исходная программа и готовый EXE 1.9.0 прошли проверку сценариев, идентификации, бака, ошибок оценки, экспорта и восстановления. Поле `identification_errors_verified` имеет значение `true`.
- Форма и графики просмотрены при 1366 × 768 и 900 × 540. Проверены обе панели, прокрутка, выбранный срез и границы легенд.
- Руководство: 28 страниц, 65 ссылок и 336 однострочных ячеек первого столбца. Все страницы отрисованы и просмотрены; отдельно проверен PDF опыта ошибок оценки.
- Полная вычитка ru-text выполнена; README содержит все 59 Python-файлов. `git diff --check` выполнен.

Перед публикацией версия дополнительно проверяется в GitHub Actions на Windows и Linux. В релиз входят EXE, руководство, этот отчёт, `release-check.json` и `SHA256SUMS.txt`.

## Ограничения и дальнейшая работа

Опыт исследует ошибки оценки, а не разброс физических свойств бака. Найденное L и его отклонение не добавляют задержку идеальному насосу. Сетка конечна; прохождение требований не доказывает устойчивость между узлами и не задаёт статистический доверительный интервал. Отсутствие подтверждённого установления за горизонт не объявляется неустойчивостью.

Сначала потребуется отдельный этап переноса методики на абсорбер; статистическая оценка неопределённости остаётся самостоятельной задачей.
