# Дорожная карта 1.12: производительность программы

Приоритет согласован после [версии 1.11](STATUS_1.11.0.md): измерить и ускорить всю программу, включая интерфейс, расчёты и работу с файлами.

| Этап | Результат | Проверка готовности |
|---|---|---|
| P01 | Сравнение с исходниками 1.11.0 на одинаковом сеансе | Время операций, события Tk, одинаковые данные |
| P02 | Устранение подтверждённых затрат | Курсор, автосохранение, расчёт бака, прокрутка |
| P03 | Повторяемый режим измерений | Исходники и EXE; временный сеанс; JSON |
| P04 | Проверка корректности и выпуск | Тесты, интерфейс, руководство, Windows/Linux |
| P05 | Внутренние разделители после уточнения пользователя | Движение, отпускание, итоговые размеры обоих графиков |

Фактические результаты и ограничения — в [отчёте 1.12.0](STATUS_1.12.0.md).

Следующая работа по производительности: уменьшить оставшиеся паузы при записи больших сеансов и экспорте, отдельно измерить холодный запуск готового EXE на компьютере пользователя. Решение о переносе на другой интерфейсный набор принимать после этих измерений. В текущем выпуске сохраняется Tkinter.

Затем — статистическая неопределённость K/T/L по согласованной методике, развитие общего контракта по опыту двух объектов и тепловая модель. Показатели качества версии 1.11 не являются доверительными интервалами.

Исправление внутренних разделителей и повторные измерения описаны в [отчёте 1.12.1](STATUS_1.12.1.md).
