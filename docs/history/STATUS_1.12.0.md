# Версия 1.12.0: производительность программы

## Выполнено

Курсор обновляет только свои линии на сохранённом фоне графика. Масштабирование, изменение размера, легенда и экспорт обновляют фон; удалённые дополнительные оси очищаются. Повторная очистка курсора не перерисовывает графики.

Неизменённый сеанс сравнивается с последним успешно записанным снимком без повторного JSON-преобразования и полной проверки. Изменённый снимок копируется до запуска фоновой записи. Закрытие и ручное сохранение дожидаются фоновой записи. Ошибка сохраняет прежний файл; следующий цикл повторяет попытку. Проверка перед записью, атомарная замена и резервная копия сохранены.

Расчёт бака использует последовательное вычисление прежнего полинома вместо генератора степеней. Малые движения колеса накапливаются; повторные настройки неизменённой компоновки пропускаются.

Добавлена команда `--performance-check`: расчёты, импорт CSV, экспорт HTML/PDF, сеанс, графики, курсор, переключение разделов, память Windows, нагрузка в покое и задержки событий. Данные пользователя не изменяются. Измерения включены в проверку исходников Linux и сборки EXE Windows; жёсткие пороги между разными компьютерами не устанавливаются.

## Сравнение с 1.11.0

Один компьютер, Python 3.14.7, одинаковый временный сеанс с 18 сочетаниями ошибок идентификации абсорбера, JSON размером 9 261 766 байт. Исходники 1.11.0 извлечены из тега; каждый запуск использует отдельные пользовательские данные. В таблице приведены медианы трёх повторов операций и максимальная пауза одного запуска. Запись и чтение измерены дважды, сетка и экспорт — по одному разу. Профилирование выполнялось отдельно от измерений.

| Операция | 1.11.0, мс | 1.12.0, мс |
|---|---:|---:|
| Расчёт бака | 222,0 | 53,9 |
| Снимок сеанса | 145,3 | 12,2 |
| Неизменённое автосохранение | 190,8 | 0,35 |
| Движение курсора | 34,9 | 1,74 |
| Максимальная пауза при изменённом автосохранении | 759,0 | 327,6 |

Полные образцы, включая операции без существенного выигрыша, находятся в [JSON измерений](performance_1.12.json). Эти времена относятся к исходникам и одному компьютеру; они не гарантируют такую же скорость на другом устройстве. Время создания интерфейса не включает запуск интерпретатора или распаковку EXE.

## Проверки

Проверяются фоновые записи, изменение снимка во время записи, повтор после ошибки, обнаружение вложенных изменений, обновление курсора без полной перерисовки, удалённые оси и малые движения колеса. Контрольный массив уровней бака совпал с 1.11.0 побитово; независимые физические проверки сохранены.

Полный локальный набор: 209 тестов, 105,448 с. Исходный режим измерений и готовый EXE завершились успешно; EXE также прошёл проверку семи сценариев, обоих объектов, идентификации, экспорта и точного восстановления.

Интерфейс сопоставлен с 1.11.0 при 1366 × 768 с двумя видимыми панелями; проверены экспорт PNG с другим DPI, масштабирование и курсор. При 900 × 540 проверен один график после расчёта.

Руководство: 32 страницы, 67 ссылок, 360 однострочных ячеек первого столбца; все страницы отрисованы и просмотрены. Полная вычитка ru-text выполнена. README перечисляет 64 Python-файла; структура и `git diff --check` проверяются перед публикацией.

Перед публикацией выполняются проверки Windows/Linux в GitHub Actions. Релиз включает проверенный EXE, руководство, этот отчёт, JSON функциональной проверки и измерений, а также контрольные суммы. После успешной проверки обновляются trunk и stable.

## Ограничения и следующий этап

При изменённом автосохранении большого сеанса остаётся заметная пауза. Копирование снимка выполняется в потоке интерфейса, а фоновая проверка и запись используют Python и конкурируют за выполнение. Явное сохранение, открытие и экспорт остаются синхронными. Tkinter сохранён: измерения выявили затраты приложения, но не доказали необходимость смены интерфейсного набора.

Сначала — оставшиеся паузы больших сеансов и экспорта, затем оценка неопределённости параметров. [Актуальная дорожная карта](ROADMAP_1.12.md).
