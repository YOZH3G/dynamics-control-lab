# Версия 1.11.0: качество идентификации

## Выполнено

Ошибка наблюдаемого отклика рассчитывается после момента `tступ + L` и не разбавляется длинным исходным участком или задержкой. Предел — 10% ожидаемой амплитуды `abs(K · Δu)`. Подгонка отклоняется при превышении; независимая проверка сохраняет результат с предупреждением и фиксированными K/T/L. Полный RMSE остаётся справочным; в обоих расчётах он взвешен по времени.

Достаточность перехода проверяется по максимальному интервалу, включая интервалы через границы участка 10–90%. Плотные кластеры больше не скрывают пропуски. Сохранены минимум пять точек перехода, пять точек исходного режима, двенадцать после ступени и три T после запаздывания.

В обеих формах и протоколах видны ошибка отклика, длительность в единицах T, число точек перехода, максимальный интервал, шум, ожидаемая амплитуда и средний остаток. JSON и сеанс сохраняют показатели. Новый снимок проверяется по собственным сигналам, модели и RMSE; повреждённый импорт отвергается. Старые снимки открываются с предложением повторить расчёт.

## Проверки

- Полный набор: 204 теста; итоговый локальный запуск — 93,413 с. Проверены отсутствие отклика при длинной предыстории, большие пропуски перехода, неравномерное время, смещение остатка, сохранение и старые результаты.
- Повреждения показателей, модели, RMSE, амплитуды и логические значения вместо чисел отклоняются. Диагностики восстановления сверены с исходными сигналами.
- Исходное приложение 1.11.0 прошло проверку семи сценариев, обоих объектов, идентификации, экспорта и восстановления. Поле `identification_quality_verified` равно `true`.
- Интерфейс просмотрен при 1366 × 768 с двумя панелями и при 900 × 540 с одним графиком. Новые показатели читаются в прокручиваемой форме.
- Руководство: 31 страница, 67 ссылок, 360 однострочных ячеек первого столбца. Все страницы руководства и трёхстраничного протокола отрисованы и просмотрены.
- Полная вычитка ru-text выполнена; формулировка длительности уточнена. README перечисляет 63 Python-файла; структура таблиц и `git diff --check` проверены.

Перед публикацией выполняются проверки Windows/Linux и сборка EXE в GitHub Actions. Релиз включает EXE из проверенной сборки, руководство, этот отчёт, `release-check.json` и `SHA256SUMS.txt`. Ветки trunk и stable обновляются после успешной проверки.

## Ограничения и следующий этап

Показатели описывают запись и согласованность модели с ней. Они не являются статистической оценкой неопределённости K/T/L. Проверка другой записи требует одинаковых сигналов, единиц и сопоставимого рабочего режима; совпадение числовых критериев не доказывает переносимость модели. CSV сигналов сохраняет прежний формат.

Следующий приоритет — статистическая неопределённость параметров; затем развитие системы моделей и тепловой объект. [Дорожная карта](ROADMAP_1.11.md).

После выпуска пользователь выбрал приоритетом производительность всей программы. Актуальная последовательность — в [дорожной карте 1.12](ROADMAP_1.12.md).
