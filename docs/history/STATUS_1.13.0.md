# Версия 1.13.0: интервалы K, T и L, нагреватель и быстрый запуск

## Неопределённость K, T и L

На страницах «Идентификация» и бака появилась кнопка «Оценить неопределённость K, T, L». Она рассчитывает 95% интервалы блочным бутстрэпом остатков: модель плюс остаток, переставленный блоками около n^(1/3) точек, подгоняется 200 раз, границы — 2,5% и 97,5% процентили. Генератор фиксирован, поэтому повтор на тех же данных даёт те же интервалы. Больше 10% отклонённых повторных подгонок помечают интервалы как ненадёжные.

Проверка на синтетических записях с известными параметрами: истинные значения попали в интервал в 90–100% опытов при белом шуме и в 83–94% при коррелированном AR(0,6). Для T и L интервалы бывают немного уже заявленных 95%; руководство это указывает. Интервалы сохраняются в сеансе и протоколах; новая подгонка их удаляет.

## Модель «Нагреватель»

Третья физическая модель — перемешиваемая ёмкость с электронагревателем: `M·c·dT/dt = W·c·(Tвх − T) + P − UA·(T − Tср)`. Уравнение интегрируется точно при постоянных на периоде входах; отклик без регулятора совпадает с аналитическим решением с точностью 6·10⁻¹⁴, энергетический баланс сходится. Датчик показывает температуру с чистым запаздыванием, при 100 °C опыт останавливается в точный момент закипания. PI управляет мощностью 0…Pmax с защитой интегратора и оценивает ошибку, IAE, перерегулирование, установление и насыщение.

Модель подключена через реестр: общий просмотр результата, экспорт JSON/CSV/HTML/PDF, сеансы и автосохранение работают без отдельного кода. Сохранённые опыты при открытии пересчитываются и должны совпасть. Описание — в разделе 25 руководства.

Операции с сеансом измерены на одном компьютере без параллельной нагрузки, в порядке «старая, новая, новая, старая», по медиане трёх повторов. Основной выигрыш дали проверка типов сигналов без цикла Python, отказ от повторной сериализации проверенных сигналов и копирование списков чисел срезом вместо `copy.deepcopy`. Запуск измеряется сценарием сборки Windows от старта процесса до готового окна.

## Поставка в виде папки

Приложение для Windows поставляется архивом `DynamicsControlLab.zip`: распакуйте его и запустите `DynamicsControlLab.exe` из папки `DynamicsControlLab`. Однофайловый EXE распаковывал себя во временный каталог при каждом запуске; папка открывается примерно вдвое быстрее. Tkinter сохранён: окно строится примерно за 1 с, импорт Tkinter занимает 5 мс.

## Интерфейс

С настоящим шрифтом интерфейса восемь из двенадцати панелей параметров оказались на 4–156 пикселей шире панели по умолчанию, и правый край полей обрезался. Растягиваемые поля теперь задают меньшую минимальную ширину и по-прежнему заполняют столбец; два заголовка карточек занимают оба столбца, а панель формул больше не запоминает прошлую ширину как минимальную. Все панели помещаются при окнах 1600 × 1000, 1366 × 768 и 1100 × 700.

## Проверка

Полный набор: 224 теста. GitHub Actions на Linux и Windows проверяет исходники, собирает приложение, запускает проверку выпуска и замеры. Проверка выпуска дополнительно рассчитывает свободный отклик и опыт PI нагревателя и восстанавливает их после перезапуска (`heater_workflow_verified`). Руководство вычитано целиком, PDF пересобран и просмотрен постранично.
