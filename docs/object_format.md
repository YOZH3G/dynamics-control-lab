# Формат описания объекта управления

Прототип этапа 4 [дорожной карты](../ROADMAP.md). Описание объекта — файл JSON без программного кода: параметры, уравнения состояния, один вход со ступенью и измеряемый выход с запаздыванием. Программа выполняет по нему расчёт и строит страницу объекта: свободный отклик, оценку K, T и L, интервалы, настройку PI и опыт с PI. Пример — [examples/heater_object.json](examples/heater_object.json): ёмкость с нагревателем; температура в расчёте по нему отличается от встроенной модели не больше чем на 10⁻¹² °C.

Загрузка описаний в программу пока не подключена: способ, которым преподаватель передаёт файл, ещё предстоит согласовать с автором проекта.

## Поля

| Поле | Содержание |
|---|---|
| `format`, `version` | `"dynamics-control-lab/object"` и `1` |
| `id` | Ключ объекта: строчные латинские буквы, цифры и `_`, до 31 символа |
| `name`, `sidebar`, `context`, `hint` | Название в списке моделей, подпись боковой панели, строка под заголовком окна и пояснение над формой |
| `parameters` | 1–40 параметров: `key`, `label`, `unit`, `default`, необязательные `minimum`, `maximum`, `strict_minimum` — `true`, если значение должно быть строго больше `minimum`, и `field` — подпись поля, если она отличается от «label, unit» |
| `states` | 1–6 переменных состояния: `key`, `label`, `unit`, `initial` — формула начального значения через параметры, `derivative` — формула производной по времени |
| `input` | Вход: `key`, `label`, `unit` и формулы через параметры: `initial` — исходное значение, `step` — величина ступени (приращение входа), `step_time` — момент ступени, `minimum` и `maximum` — пределы |
| `output` | Измерение: `key`, `label`, `state` — ключ измеряемой переменной состояния, `delay` — формула чистого запаздывания |
| `horizon`, `sample_time` | Формулы горизонта опыта и периода расчёта; `horizon` / `sample_time` — не больше 50 000 периодов |
| `pi` | Необязательные значения по умолчанию для формы PI: `setpoint`, `gain`, `integral_time` |

## Формулы

Формула — арифметическое выражение: числа, имена, `+ - * /`, степень `**` с показателем не больше 100 по модулю, скобки и функции `exp`, `log`, `sqrt`, `sin`, `cos`, `tan`, `abs`, `min`, `max`. В производных доступны параметры, переменные состояния, вход и время `t`; в остальных формулах — только параметры. Формулы разбираются как дерево выражения и проверяются до расчёта; атрибуты, вызовы других функций, строки, сравнения и любые другие конструкции отклоняются. Код из файла никогда не выполняется.

## Расчёт

На каждом периоде вход постоянен; состояния интегрируются методом Рунге–Кутты 4-го порядка, период делится на четыре шага. Измерение — выбранное состояние с чистым запаздыванием. В опыте с PI регулятор управляет входом по измерению в пределах от `minimum` до `maximum` с защитой от насыщения интегратора, как у встроенных объектов. Сохранённые расчёты и оценки при открытии сеанса пересчитываются по описанию и сверяются с сохранёнными; при расхождении сеанс не открывается.
