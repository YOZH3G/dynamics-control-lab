# Дорожная карта

Текущая выпущенная версия — 1.14.0. Здесь перечислены согласованные этапы и их состояние. Планы и отчёты прошлых версий хранятся в [docs/history](docs/history/), последний отчёт — [1.14.0](docs/history/STATUS_1.14.0.md).

Все согласованные этапы выполнены в версии 1.14.0:

| Этап | Результат |
|---|---|
| Обрезанный параметр на странице «Чувствительность» | «Постоянная времени T» видна целиком при размерах окна 1600 × 1000, 1366 × 768 и 1100 × 700 |
| Проверка кода и описание для агентов | ruff ищет ошибки в CI; `AGENTS.md` описывает поставку ZIP и команду проверки |
| Нестабильная проверка выпуска в CI на Windows | Предел времени проверок — 180 с (было 60 и 90 с); журнал сборки показывает длительность каждой проверки |
| Покрытие интервалов K, T и L | Длина блока исследована на 108 опытах с шумом AR(1) с коэффициентом 0,6: более длинные блоки покрытие заметно не улучшили, метод оставлен, цифры в руководстве уточнены |
| Идентификация нагревателя | K, T и L по свободному отклику с шумом датчика, интервалы и настройка PI по модели на странице нагревателя |

Новых согласованных этапов нет. Обратная связь студентов и преподавателей пока недоступна. Когда она появится, приоритеты будут пересмотрены по её итогам.
