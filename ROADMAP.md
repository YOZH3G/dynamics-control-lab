# Дорожная карта

Текущая выпущенная версия — 1.13.0. Здесь перечислены согласованные этапы и их состояние. Планы и отчёты прошлых версий хранятся в [docs/history](docs/history/), последний отчёт — [1.13.0](docs/history/STATUS_1.13.0.md).

Все согласованные этапы выполнены в версии 1.13.0:

| Этап | Результат |
|---|---|
| Паузы при записи больших сеансов и экспорте | Запись сеанса быстрее на 38%, чтение — на 45%, экспорт HTML — на 19%, PDF — на 15% |
| Холодный запуск EXE | Поставка ZIP с папкой: окно открывается за 1,2–1,6 с вместо 4,2–4,7 с; Tkinter сохранён |
| Неопределённость K, T и L | 95% интервалы блочным бутстрэпом остатков на страницах «Идентификация» и бака |
| Тепловая модель | Ёмкость с нагревателем подключена через реестр моделей, с собственной страницей, PI и общим просмотром результата |

Новых согласованных этапов нет. Обратная связь студентов и преподавателей пока недоступна. Когда она появится, приоритеты пересматриваются по её итогам.
